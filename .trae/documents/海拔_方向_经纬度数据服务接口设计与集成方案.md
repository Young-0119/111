## 目标与使用场景
- 为预览叠加水印与拍照合成水印统一提供海拔、方向、经度、纬度数据（含状态与格式化）。
- 在 `entry/src/main/ets/views/WatermarkOverlay.ets:186–334` 展示；在 `camera/src/main/ets/cameramanagers/PhotoManager.ets` 的水印生成与缓存预热使用（`prewarmWatermarkInfo:185–203`、`drawWatermarkWithCanvas:1021–1105`）。

## 接口设计
- 文件：`camera/src/main/ets/dataservices/GeoDataService.ets`
- 单例服务 `GeoDataService` 实现接口 `IGeoDataService`，面向 UI 与拍照管线统一提供快照与订阅。

```ts
export enum DataStatus { Loading, Ready, Error }

export interface AltitudeData {
  status: DataStatus
  meters?: number
  display: string
}

export interface DirectionData {
  status: DataStatus
  degrees?: number
  cardinal?: '东'|'东北'|'北'|'西北'|'西'|'西南'|'南'|'东南'
  display: string
}

export interface LongitudeData {
  status: DataStatus
  degrees?: number
  hemisphere?: 'E'|'W'
  display: string
}

export interface LatitudeData {
  status: DataStatus
  degrees?: number
  hemisphere?: 'N'|'S'
  display: string
}

export interface GeoSnapshot {
  altitude: AltitudeData
  direction: DirectionData
  longitude: LongitudeData
  latitude: LatitudeData
  timestamp: number
}

export interface IGeoDataService {
  start(context: any): Promise<void>
  stop(): void
  getSnapshot(): GeoSnapshot
  onUpdate(cb: (s: GeoSnapshot) => void): number
  removeListener(id: number): void
}
```

## 数据来源与算法
- 海拔/经纬度：GNSS（`@ohos.location`），优先定位成功数据；失败或超时进入 Error。
- 方向：设备姿态（`@ohos.sensor` 旋转向量/地磁系）计算方位角 `degrees ∈ [0,360)`；根据屏幕横屏旋转角修正。
- 横屏修正：读取显示旋转（`@ohos.display`/`@ohos.window`），`degrees = (azimuth - rotationDegrees + 360) % 360`。
- 方位文案：将 `degrees` 映射八方向（每 45° 区间），按需要展示与度数组合为 `cardinal + floorOffset°`。

## 状态与格式规范
- 统一默认值：
  - 海拔：Loading → `获取中`，Error → `获取失败`，Ready → `{meters}m`（示例 `20m`）。
  - 方向：Loading → `获取中`，Error → `获取失败`，Ready → `东南{deg}°`（示例 `东南25°`，横屏修正后方位）。
  - 经度：Loading → `获取中`，Error → `获取失败`，Ready → `{abs(deg).toFixed(6)}°E/W`（示例 `110.111111°E`）。
  - 纬度：Loading → `获取中`，Error → `获取失败`，Ready → `{abs(deg).toFixed(6)}°N/S`（示例 `19.111111°N`）。
- 超时策略：定位与传感器首次启动 8s 未得数据 → Error；随后继续后台订阅以便恢复。
- 小数位：经纬度保留 6 位；海拔为整数或 1 位小数（可配置）。

## 权限与容错
- 清单新增定位权限（精确/粗略），传感器权限按平台要求；首次进入提示授权并优雅降级（继续显示 Loading → Error）。
- 无硬件支持或被系统关闭：方向与海拔进入 Error，但经纬度若可从最近定位补偿则 Ready。
- 低频刷新与节流：方向 10Hz→UI 2Hz；定位 1Hz 或按回调节流，减小功耗与 UI 抖动。
