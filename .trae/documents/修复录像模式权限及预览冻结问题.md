# 隐藏录像功能计划

## 任务目标

隐藏应用中的录像相关入口，保留拍照、水印、指南针等功能，以便于申请应用上线。代码逻辑需保留以便后续恢复。

## 修改计划

### 1. 修改 `ModeButtonsView` (Entry 模块)

* **文件**: `entry/src/main/ets/views/ModeButtonsView.ets`

* **操作**:

  * 修改 `cameraModeButtons` 数组，注释掉或移除 `CameraMode.VIDEO` 相关的配置项。

  * 这样界面上就只会显示“拍照”模式，用户无法切换到录像模式。

### 2. 检查 `OperateButtonsView` (Entry 模块)

* **文件**: `entry/src/main/ets/views/OperateButtonsView.ets`

* **分析**: 该文件根据 `previewVM.isPhotoMode()` 来判断显示拍照按钮还是录像按钮。只要 `ModeButtonsView` 限制了只能处于 Photo 模式，这里就只会显示拍照按钮。录像相关的控制按钮（暂停、继续等）也依赖于 `isVideoMode()` 或 `videoManager.isRecording()`，因此只要无法进入 Video 模式，这些 UI 逻辑自然不会触发。

* **操作**: 无需修改，依赖模式切换的入口控制即可。

### 3. 检查权限申请 (Entry 模块)

* **文件**: `entry/src/main/module.json5`

* **分析**: 虽然隐藏了录像入口，但为了过审，是否需要移除 `ohos.permission.MICROPHONE`？用户提到“代码先保留”，且只是为了“隐藏功能”，通常不需要移除权限声明，除非审核方明确要求应用未使用的权限必须移除。考虑到用户说“代码先保留”，我们暂时保留权限配置，仅在 UI 层屏蔽入口。

* **决定**: 移除 `ohos.permission.MICROPHONE`。

## 验证

* 启动应用，检查底部模式切换栏，确认只有“拍照”选项（或者根本不显示切换栏，如果只有一个选项的话）。

* 确认无法滑动或点击进入录像模式。

* 确认拍照、水印、指南针功能正常使用。
