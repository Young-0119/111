## 概览
- 目标：在应用内调用高德开放平台（Amap）REST API，获取逆地理（位置编码）与天气数据，并把结果用于水印显示。显示规则：
  - 地点：未获取 → `获取中`；获取失败 → `获取失败`；获取到 → `省/直辖市·市/县·区·街道*号`（优先使用门牌号，若无则只到街道）
  - 天气：未获取 → `获取中`；获取失败 → `获取失败`；获取到 → `{天气} {温度}℃ {风向}{风力}级 湿度{湿度}%`（示例：`晴 10℃ 东北风2级 湿度71%`）

## 权限与密钥（准备工作）
1. 在高德官网申请 Web 服务 Key（REST API Key）。不要把明文 Key 提交到代码仓库。建议放在本地 `build-profile.json5` 的签名/私有配置中或 CI 的 Secret 中。
2. module.json5 中添加必要权限（由用户确认并授权）：
   - 网络访问（Internet）：`ohos.permission.INTERNET`（或等效权限）
   - 定位权限（如果要使用设备定位）：例如 `ohos.permission.LOCATION` / `ohos.permission.ACCESS_FINE_LOCATION`（请根据目标 SDK 校对精确权限名）

## 服务实现（代码结构建议）
- 新增服务模块：`entry/src/main/ets/services/AmapService.ets`（或 `entry/src/main/ets/utils/AmapService.ets`）
- 暴露的异步方法：
  - `async reverseGeocode(lat: number, lon: number): Promise<LocationResult>`
  - `async getWeatherByAdcode(adcode: string): Promise<WeatherResult>`
  - `async fetchLocationAndWeather(lat: number, lon: number): Promise<{location: string, weather: string}>`（组合调用，供 UI 直接使用）

- HTTP 调用：使用系统提供的 HTTP 客户端（例如 `@ohos.net.http` / 平台提供的 fetch），示例参数：
  - 逆地理：`https://restapi.amap.com/v3/geocode/regeo?key=YOUR_KEY&location=${lon},${lat}&extensions=all`。
    - 解析 `regeocode.addressComponent`：取 `province`、`city`、`district`、`streetNumber.street` 与 `streetNumber.number`。
  - 天气：`https://restapi.amap.com/v3/weather/weatherInfo?key=YOUR_KEY&city=${citycode}&extensions=all` 或使用 `adcode` 对应的城市码（从逆地理结果中获取 `adcode` 或 `citycode`）。解析 `lives[0]` 或实时天气字段（`weather`, `temperature`, `winddirection`, `windpower`, `humidity`）。

## UI 触发点与更新（代码位置建议）
- 在 `WatermarkOverlay.ets`：
  - 初始化时（aboutToAppear / loadOrganization / updateTimestamp 的启动流程中）触发一次 `AmapService.fetchLocationAndWeather()`。
  - 当位置信息有显著变化（如果支持实时定位）或用户手动刷新时再次调用。
  - 在调用前设置占位文案 `获取中`；若失败设置为 `获取失败`；成功则用服务返回的格式化字符串填充 `this.watermarkInfo.location` 与 `this.watermarkInfo.weather`。

## 显示格式与优先级
- 地点格式化：
  - 如果 `streetNumber.number` 存在：`${province}·${city}·${district}·${street}${streetNumber.number}号`
  - 否则：`${province}·${city}·${district}·${street}`（若 `street` 也无，则降级到 `${province}·${city}·${district}`）
- 天气格式化：组合 `weather`（中文）、`temperature`、`winddirection`+`windpower`、`humidity`，示例：`晴 10℃ 东北风2级 湿度71%`。

## 错误处理与缓存
- 缓存：为避免频繁请求，缓存在内存中并设置 TTL（建议 5 分钟）。当缓存未过期时直接返回缓存值。
- 失败重试：网络失败可重试 1 次（指数退避短延时）。若仍失败，记录日志并返回 `获取失败`。
- 离线处理：若设备无网络，直接返回 `获取失败` 并可在 UI 展示离线提示。

## 隐私与合规
- 位置数据为敏感数据，确保已经向用户申请并得到授权。仅在用户授权时才采集并调用逆地理接口。
- 不在日志或持久化中写入精确位置信息（仅写入模糊/汇总文本或 appId 等非敏感信息）。

async function reverseGeocode(lat:number, lon:number) {
  const url = `https://restapi.amap.com/v3/geocode/regeo?key=${KEY}&location=${lon},${lat}&extensions=all`;
  const res = await httpGet(url);
  // if res.status==1
  const comp = res.regeocode.addressComponent;
  return {
    province: comp.province || '',
    city: comp.city || comp.province || '',
    district: comp.district || '',
    street: comp.streetNumber && comp.streetNumber.street || '',
    number: comp.streetNumber && comp.streetNumber.number || '',
    adcode: res.regeocode.addressComponent.adcode || '',
  };
}

async function getWeatherByAdcode(adcode:string) {
  const url = `https://restapi.amap.com/v3/weather/weatherInfo?key=${KEY}&city=${adcode}&extensions=all`;
  const res = await httpGet(url);
  const w = res.lives && res.lives[0];
  return {
    weather: w?.weather || '',
    temp: w?.temperature || '',
    windDir: w?.winddirection || '',
    windPower: w?.windpower || '',
    humidity: w?.humidity || ''
  }
}
